# Example Project

This folder is a fully filled-out example of what a project folder under `PROJECTS/` can look like. The "company" and "project" are fictional. The structure is the part to copy.

## What's in here

- **`project-context.md`** — the file Claude reads when you mention this project. Team, stack, status, decisions, links. Filled out completely so you can see what "good" looks like.
- **`project-brief.md`** — the doc you'd write at project kickoff. Defines vision, scope, success criteria. Useful for new projects, optional for established ones.
- **`decisions.md`** — a running log of significant decisions and the reasoning. Lightweight ADR.

## When you're ready to delete this

This folder is just an example. Once you've created your own projects, you can delete `Example Project/` entirely. The contents won't help Claude do anything for *you* — it's only useful while you're still figuring out the shape.

## The fictional setup

- **Company:** Wildgate Outdoors — mid-sized outdoor gear retailer (~600 employees), DTC and wholesale channels, headquartered in Boulder, CO
- **Project:** Spring 2027 Loyalty Program Relaunch — replacing a stale points program with a tier-based experience program
- **Why a non-software example?** Because the template is for anyone, not just engineers. A loyalty relaunch touches marketing, ops, IT, customer service, legal, and finance — a realistic cross-functional initiative most readers can map to their own work.
