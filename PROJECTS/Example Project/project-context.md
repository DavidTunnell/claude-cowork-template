# Project Context: Spring 2027 Loyalty Program Relaunch

**Last Updated:** 2027-02-12

> *This is an example project. The company (Wildgate Outdoors) and people are fictional. See `Example Project/README.md` for context.*

## Overview

Wildgate's loyalty program ("Wildgate Rewards") has been a flat 1%-back points program since 2019. Engagement has dropped each of the last three years, and analysis showed top-tier customers don't see the program as differentiating. This project replaces it with a four-tier experience program ("Wildgate Trail Club") that mixes points, early access, exclusive guides, and partner experiences. Targeting full launch April 15, 2027.

## Current Status

- **Phase:** Design (transitioning to Pilot late February)
- **Current focus:** Finalizing tier benefits with Merchandising and confirming legal copy with outside counsel. Build cycle for the email program kicks off Feb 24.
- **Last major milestone:** Discovery research wrapped Jan 30 (12 customer interviews, 1,400 survey responses, competitive teardown).
- **Next milestone:** Pilot soft-launch with employees + 500 invited customers, March 17, 2027.

## How Work Gets Delivered

- **Cadence:** Weekly project standup (Mondays, 30 min) + bi-weekly steering committee with Priya + ad-hoc working sessions per workstream.
- **Workflow / stages:** Asana project with phases as sections. Tasks move through `Backlog → In Progress → In Review → Done`.
- **Who approves what:**
  - Tier benefits: Priya
  - Creative: Devon, then Priya for sign-off
  - Legal copy: Outside counsel + General Counsel sign-off
  - Site / system changes: Aiden (technical) + Maya (UX)
  - Communication plan: Maya
- **Release strategy:** Phased. Pilot (500 customers) → existing-member migration (240k) → public sign-ups. Email comms staggered over the launch week to manage support volume.

## Project Conventions

- **Asana is the source of truth for tasks.** Anything decided in Slack must be summarized in the relevant Asana task within 24 hours.
- **Every meeting has a doc.** Notes go in the Notion project space, linked from the Asana task.
- **Naming:** All program collateral uses "Wildgate Trail Club" (not "Trail Club" alone, not "Loyalty Program 2.0," not "Wildgate Rewards 2"). Consistency matters for SEO and brand recall.
- **Tier names are capitalized:** Hiker, Climber, Summiteer, Pathfinder. The program itself is lowercase "trail club" in body copy except in headlines.
- **Customer Service is informed before any external comm goes live.** No exceptions. They get blindsided once and trust evaporates.
