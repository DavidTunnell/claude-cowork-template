# PROJECTS

This is where you describe the projects, initiatives, or accounts that you actively work on. When you ask Claude about "the loyalty relaunch" or "the migration" or "the Q3 campaign," it should be able to look here for full context: who's on the team, what stage you're in, what tools and systems are involved, and what's been decided so far.

## How to use this folder

1. **For each project, create a subfolder.** Name it whatever you'd naturally call it in conversation. Spaces are fine: `PROJECTS/Spring 2027 Loyalty Relaunch/`.
2. **Drop in a project context file.** Copy `TEMPLATES/project-context.md` into the new folder and fill it in.
3. **Optionally, drop in a project brief.** If the project is just kicking off and you don't have shared docs yet, copy `TEMPLATES/project-brief.md` too.
4. **Add anything else useful.** A meeting notes folder, a `decisions.md`, a `risks.md` — whatever helps Claude understand the work. The example project demonstrates one structure.

## See `Example Project/`

A fully filled-out fictional example showing what a populated project folder looks like. Use it as a reference for shape, not a strict template — your project's needs will be different.

## Don't put confidential info here unless your folder is configured for it

These files are read by Claude every session. If you're using Cowork on a personal machine, that's local-only and probably fine for sensitive info. If this folder is going into a shared repo, sanitize before pushing.
